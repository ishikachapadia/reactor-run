# Reactor Run

A fast, game-like browser experience built with vanilla JavaScript — speed,
visual intensity, and immediate feedback loops, with dynamic progression and
clear UI states throughout a run.

**Live demo:** https://ishikachapadia.github.io/reactor-run/

## Built with

- Semantic HTML5 + custom CSS
- Vanilla JavaScript, split into modules: board, hero, enemies, UI, sound, data
- GSAP for motion and timing
- Tone.js for synthesized sound (no audio files)
- Hand-drawn SVG sprites and level data in JSON

## Run locally

Open `index.html` in a browser — no build step. (Serve the folder with any
static server if your browser blocks local file fetches of `data.json`.)
